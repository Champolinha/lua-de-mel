Configure seu App
Siga os passos abaixo para conectar o app ao seu Google Sheets. Você só precisa fazer isso uma vez!
1
Criar projeto no Google Cloud
Acesse console.cloud.google.com, clique em Novo projeto, dê um nome como "Lua de Mel App" e clique em Criar.
2
Ativar a Google Sheets API
No menu lateral, vá em APIs e Serviços → Biblioteca. Pesquise "Google Sheets API", clique nela e depois em Ativar. Repita o processo para "Google Drive API".
3
Criar credenciais OAuth 2.0
Vá em APIs e Serviços → Credenciais → Criar Credenciais → ID do cliente OAuth.

Tipo: Aplicativo da Web
Nome: Lua de Mel App
Origens JS autorizadas: https://SEU-USUARIO.github.io e http://localhost

Clique em Criar e copie o ID do cliente.
